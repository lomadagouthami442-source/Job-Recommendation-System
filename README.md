# Job Recommendation System
## About the Project
This project helps users find suitable jobs based on their skills.
## How It Works
1. The user enters their skills.
2. The program checks the skills required for different jobs.
3. It compares the user's skills with the job skills.
4. It shows the jobs that match the user's skills.
## Example
User enters:
Python SQL
The system may recommend:
- Python Developer
- Data Analyst
- Data Scientist
## Technologies Used
- Python
- Pandas
- Streamlit
- CSV
## Project Files
- app.py - Main Python program
- jobs.csv - Job and skill data
